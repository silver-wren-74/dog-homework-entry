One funny single-line excuse a dog gives after being caught eating the
homework — under 200 characters, written by `main.py` to
`/output/entry.txt`:

> It had my name on it, so in dog law it was mine. I ate it. No regrets,
> no crumbs, no witnesses.

The dog as a little lawyer who believes it did nothing wrong: the homework
had my name on it, so in dog law it was mine — and then the dog ate the
evidence itself. No regrets, no crumbs, no witnesses.

## Run

```sh
python3 main.py   # writes /output/entry.txt (95 characters, 1 line)
```
